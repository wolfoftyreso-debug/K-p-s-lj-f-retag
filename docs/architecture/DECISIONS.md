## Ordinary reversible engineering choices

Within an approved package, engineering may choose standard library HTTP routing, package/file naming, formatter configuration, narrow ports, query generation where useful, maintained test tools and supported dependency patches. Pin exact versions when installed and document rationale. Do not seek a new approval for every routine choice. Package approval does not permit substituting a security/business policy that the register leaves unresolved.
